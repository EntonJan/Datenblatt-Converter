# EPS Datenblatt-Converter

Windows-Programm (Python), das Hersteller-Datenblätter (PDF) einliest, die Werte den EPS-Feldern zuordnet
und daraus EPS-Datenblätter (Deutsch und Englisch) erzeugt. Später: Übertragung der Artikel nach Weclapp.

Grundlage: Pflichtenheft Produktdaten-Pipeline (Stand 15.10.2026).

Status: Version 1 in Vorbereitung.
